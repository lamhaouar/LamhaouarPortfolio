Hemp / Bamboo

2026 Material Study

This project is an experimental assembly system designed for eco-tourism cabins. The structure explores the integration of hempcrete for thermal mass, tensioned straps for shear resistance, and invasive bamboo harvested locally for structural framing and cladding. By utilizing these alternative materials, the project aims to create a sustainable, low-carbon building system that responds to its ecological context.
